VRChat Sync Portal

This system enables secure, real-time avatar synchronization through a browser extension and custom API integration. NOT AFFILIATED WITH TWITCH, GITHUB, CHROME, VRCHAT OR STREAM ELEMENTS

Setup Guide

1. Download the browser extension: extension.mock
2. Download the program via GitHub (github.mock) or access the hosted version (apiurl.mock)
3. Open any VRChat avatar page while logged in using Chrome on desktop
4. Open the extension and set a 4-digit PIN
5. Close the extension, wait ~10 seconds, then reopen it
6. Copy the generated session token
7. Set up StreamElements by following a tutorial on YouTube
8. Create a chatbot command using the generator below
9. If the avatar page is closed for ~40 seconds, the token must be refreshed
10. For support, contact: example@example.com
